# Road Management System using TensorFlow

## Overview

Road Management System is a computer vision project designed to detect and analyze road conditions using TensorFlow and deep learning techniques.

The system processes video input and identifies road damage conditions to support infrastructure monitoring and maintenance activities.

## Features

* Road damage detection from video input
* TensorFlow-based object detection
* Video processing pipeline
* Predefined road damage classification
* Automated analysis workflow

## Tech Stack

* Python
* TensorFlow
* OpenCV
* Object Detection API

## Project Structure

* object_detection_video.py — Main object detection process
* test-video-example.py — Video testing script
* predefined_classes.txt — Object labels
* road-damage-label-map.pbtxt — Detection label map
